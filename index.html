Structure des variables

Typage automatique indicatif. Il pourra être rendu modifiable dans une prochaine version, notamment pour distinguer identifiants et mesures numériques.
Importe un jeu de données pour afficher les variables.

Aperçu des données

Prudence : prototype de démonstration. Ne charge pas de données nominatives, sensibles ou médico-légales réelles. Le stockage local du navigateur n'est pas un coffre-fort ; conserve une copie du fichier .statlab dans un emplacement approuvé. Aucun téléversement réseau n'est effectué par cette application.
