STATLAB 0.4 — PAQUET PWA DE TEST

CONTENU
- index.html : application StatLab 0.4
- manifest.webmanifest : identité et paramètres d’installation
- sw.js : cache hors ligne (cache v04)
- icons/ : icônes d’application

NOUVEAUTÉS EXPÉRIMENTALES
- Comparaison de deux groupes indépendants : Student, Welch et Mann-Whitney (approximation normale).
- Bland-Altman classique et logarithmique pour paires de mesures alignées ligne par ligne.
- Biais moyen, limites d’accord, IC du biais, IC approximatifs des limites, recherche de biais proportionnel et graphique.

LIMITES IMPORTANTES
Cette version est expérimentale et n’est pas validée pour un usage professionnel ou médico-légal. Les IC des limites d’accord sont approximatifs. Le test de pente ne prouve pas l’absence de biais proportionnel lorsqu’il n’est pas significatif. Les mesures répétées par sujet ne sont pas prises en charge. Chaque ligne doit correspondre à une paire de mesures du même échantillon. En mode logarithmique, toutes les valeurs doivent être strictement positives.

SÉCURITÉ ET DONNÉES
Le traitement est conçu pour rester dans le navigateur ; aucun téléversement de données n’est prévu. Le stockage local n’est pas un coffre-fort. Ne pas charger de données nominatives, sensibles ou médico-légales réelles dans ce prototype. Exporter régulièrement les projets .statlab et les conserver dans un emplacement approuvé.

MISE À JOUR
Remplacer les fichiers index.html et sw.js à la racine du dépôt GitHub Pages. Conserver manifest.webmanifest et le dossier icons. Après publication, recharger l’application ; si l’ancienne version persiste, fermer l’onglet puis le rouvrir ou vider les données du site dans le navigateur.

VALIDATION
Contrôles de syntaxe JavaScript et vérifications de fonctionnement élémentaire à effectuer avant utilisation. Aucun audit de sécurité, validation métrologique, ni validation statistique indépendante n’a été réalisé.
